# PIUKISTAN 3D asset register

The 2D placeholder renderer has been replaced by a Three.js 3D runtime. Visual assets are streamed from public online sources rather than copied into this repository.

## Runtime libraries

| Asset | Source | License | Usage |
|---|---|---|---|
| Three.js 0.185.1 | https://threejs.org/ / https://www.npmjs.com/package/three | MIT | 3D renderer, scene graph, GLTF loading |
| GLTFLoader | Three.js examples | MIT | glTF 2.0 model loading |

## Important

The game does **not** redistribute these third-party files as a standalone asset pack. They are requested at runtime from their original public hosts. If a source disappears or changes its license, replace the URL and update this register.

## Fonts

Cinzel and IM FELL English are loaded from Google Fonts when available. System serif fallbacks are provided.
